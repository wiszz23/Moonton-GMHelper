## 1. 项目概述

### 1.1 工具定位

**用户 GM 值管理工具** 是一个浏览器单文件 HTML 工具，为游戏运营人员提供**快速、直观、批量管理**游戏用户 GM 值的能力。与"通用指令编辑器"类似理念，零依赖，双击打开即可使用。

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **单文件部署** | 无需服务器部署，浏览器直接打开 HTML 即可 |
| **零外部依赖** | 纯 JavaScript + CSS，不依赖任何框架/库 |
| **离线可用** | 支持离线数据编辑，后续一键同步到数据库 |
| **批量操作** | 支持批量编辑、批量导入、批量推送 |
| **实时搜索** | 快速搜索用户、支持拼音首字母和模糊匹配 |
| **历史追踪** | 记录每次修改的时间、修改者、修改内容 |
| **导入/导出** | JSON/CSV 导出，支持从外部数据源导入 |
| **权限管理** | 可配置管理员白名单，防止误操作 |

### 1.3 适用场景

- 📊 **日常运营**：快速调整用户 GM 值（等级、经验、钻石等）
- 🔄 **批量操作**：导入 CSV/JSON，批量修改数百用户
- 📈 **数据核对**：查看所有用户 GM 值，发现异常
- 🔙 **数据恢复**：导出备份，历史版本恢复
- 🎯 **活动配置**：活动期间快速为目标玩家调整属性

#### 4.1.2 搜索算法

```
搜索关键词支持：
1. 用户名（中文/英文）
   - "玩家A" → 精确/模糊匹配
   - "A" → 拼音首字母匹配

2. UID / 角色ID
   - "10001" → 精确匹配
   - "1001*" → 前缀匹配

3. 组合条件
   - "玩家A 50级" → 同时包含
   - "uid:10001 level:50" → 字段搜索

时间复杂度：O(n)，支持实时搜索，1000条数据 <100ms
```

#### 4.1.3 筛选条件

```
可选筛选项：
- 等级范围：[最小] ~ [最大]
- 经验值范围：[最小] ~ [最大]
- 钻石范围：[最小] ~ [最大]
- 修改时间：[开始日期] ~ [结束日期]
- 修改者：[下拉选择管理员]
- 状态：全部 / 已修改 / 待同步 / 已同步

筛选支持组合，结果实时更新
```

#### 4.2.3 修改验证

```
编辑时触发：

1. 类型验证
   - 等级：整数，1-999
   - 经验值：整数，≥0
   - 钻石：整数，≥0

2. 业务逻辑验证
   - 等级 > 99 时警告
   - 钻石 > 999999 时警告

   - 若用户在其他浏览器/管理员被修改过
   - 显示冲突提示：[忽略] [覆盖] [合并]

4. 权限检查
   - 是否有修改权限
   - 修改者是否在白名单
```

### 4.3 数据导入模块

#### 4.3.1 支持格式

**格式 1：CSV**

**格式 2：JSON**
```json

  }
]
```

#### 4.3.2 导入流程

```
1. 点击"导入"按钮
   ↓
2. 选择文件 (CSV / JSON)
   ↓
3. 预解析
   - 检测格式
   - 识别列头
   - 数据行计数
   ↓
4. 预览窗口
   ┌─────────────────────────────┐
   │ 导入预览                    │
   ├─────────────────────────────┤
   │ 文件：data.csv              │
   │ 行数：150                    │
   │ 合法：148 ✓                  │
   │ 异常：2 ⚠️                   │
   │                             │
   │ 异常行:                      │
   │ - 行3：缺少character_id     │
   │ - 行7：level=2000（超出范围)│
   │                             │
   │ [忽略异常] [修改文件] [导入]│
   └─────────────────────────────┘
   ↓
5. 执行导入
   - 本地合并（去重 + 覆盖）
   - 标记为"待同步"
   ↓
6. 同步数据库 / 撤销
```

#### 4.3.3 去重策略

```
导入时，同名用户处理规则：
1. 若新数据 + 旧数据完全相同 → 跳过
2. 若新数据不同 → 询问：
   [保留旧值] [覆盖为新值] [手动合并]
3. 支持"全部应用"快速决策
```

## 5. 数据结构

### 5.1 用户对象

```javascript
{
  // 基础信息
  uid: String,              // 唯一用户ID
  username: String,         // 用户名
  character_id: String,     // 角色ID

  // GM 值
  level: Number,            // 等级 (1-999)
  exp: Number,              // 经验值 (≥0)
  diamond: Number,          // 钻石 (≥0)

  // 可扩展属性
  gold: Number,             // 金币
  vip_level: Number,        // VIP等级
  title: String,            // 称号

  // 元数据
  last_modified: ISO8601,   // 最后修改时间
  modified_by: String,      // 修改者用户名
  created_at: ISO8601,      // 创建时间

  // 本地标记
  _state: "unchanged" | "modified" | "pending" | "synced",
  _dirty_fields: String[],  // 修改过的字段列表
  _original: Object         // 修改前的完整备份
}
```


### 6.2 API 接口列表

#### 6.2.1 查询用户列表

```
GET /api/gm/users?page=1&limit=100&search=&filters=

参数：
  page: Number (默认 1)
  limit: Number (默认 100, 最大 1000)
  search: String (搜索关键词)
  filters: JSON (筛选条件)
    - level_min, level_max
    - exp_min, exp_max
    - diamond_min, diamond_max
    - modified_after, modified_before
    - modified_by

响应：
{
  "code": 0,
  "data": {
    "users": [User],
```
