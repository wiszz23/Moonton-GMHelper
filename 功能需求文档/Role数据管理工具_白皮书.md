## 1. 项目概述

### 1.1 工具定位

**Role 数据管理工具** 是一个浏览器单文件 HTML 工具，提供**表格展示 + JSON 编辑**混合模式，让运营人员快速查询、编辑、更新游戏 Role（角色）数据。

### 1.2 核心功能

- 🔍 **加载 Role 数据**：从数据库一次性加载所有 role 信息
- 📊 **表格展示**：美观的表格视图，快速浏览所有 role
- ✏️ **编辑数据**：表格 / JSON 两种模式自由切换
- 💾 **实时保存**：编辑后直接 POST 更新到数据库
- 🔄 **实时刷新**：修改后立即看到最新数据

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| 单文件部署 | 浏览器双击打开即可 |
| 零外部依赖 | 纯 JavaScript + CSS |
| 混合编辑模式 | 表格浏览 + JSON 编辑 |
| 全量数据加载 | 一次性加载所有 role |
| JSON 美化 | 编辑器支持格式化、验证、高亮 |
| 快速编辑 | 表格内直接编辑字段 |
| 实时推送 | 修改后直接 POST 更新数据库 |
| 本地缓存 | 支持离线浏览和编辑恢复 |

## 3. 核心功能

### 3.1 初始化加载

```javascript
页面加载时自动触发：
1. 从后端 GET /api/roles 获取所有 role
2. 返回 role 数据数组
3. 本地缓存到 localStorage
4. 渲染表格展示所有 role
```

### 3.2 搜索与筛选

```javascript
支持搜索条件：
1. Role 名称 - 模糊匹配
2. Role ID - 精确匹配
3. Role 类型 - 下拉筛选
```

### 3.3 编辑模式

**模式 A：表格内编辑（可选）**
```
双击表格单元格 → 进入编辑状态 → Enter 保存 / Esc 取消
```

**模式 B：JSON 编辑（主要）**
```
1. 点击表格中的 role 行
2. 右侧显示完整 JSON
3. 自由编辑 JSON 内容
4. 点击"推送到 DB"保存
```

### 3.4 保存流程

```javascript
用户编辑后点击"推送到 DB":

1. 验证 JSON 格式是否合法
2. POST /api/roles 更新数据
3. 等待服务器响应
4. 刷新本地缓存
5. 更新表格显示
6. 显示成功提示
```

### 3.5 导入导出

**导出**:
```
点击"导出 JSON" → 下载所有 role 的 JSON 文件
文件名: roles_{timestamp}.json
```

**导入**:
```
点击"导入 JSON" → 选择文件 → 预览 → 批量推送到 DB
```

## 5. 后端 API

### 5.1 API 列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/roles` | 获取所有 role |
| GET | `/api/roles/:id` | 获取单个 role |
| POST | `/api/roles` | 创建或更新 role |
| DELETE | `/api/roles/:id` | 删除 role |

### 5.2 请求/响应详解

```javascript
// 1. 获取所有 role
GET /api/roles

Response:
{
  "code": 0,
  "data": {
    "roles": [
      { "id": 1, "name": "战士", "type": "DPS", ... },
      { "id": 2, "name": "法师", "type": "MAGE", ... }
    ],
    "total": 50
  }
}

// 2. 更新单个 role
POST /api/roles
Body:
{
  "id": 1,
  "name": "战士",
  "type": "DPS",
  "base_stats": { "hp": 1000, "attack": 100 },
  ...
}

Response:
{
  "code": 0,
  "message": "更新成功",
  "data": { "id": 1, "name": "战士", ... }
}

// 3. 删除 role
DELETE /api/roles/1

Response:
{
  "code": 0,
  "message": "删除成功"
}
```

## 8. 使用流程

### 8.1 基础流程

```
1. 双击打开 gm-role-manager.html
   ↓
2. 自动从数据库加载所有 role
   ↓
3. 表格显示所有 role 信息
   ↓
4. 搜索或筛选特定 role
   ↓
5. 点击表格行进入编辑
   ↓
6. 右侧显示 role 的完整 JSON
   ↓
7. 编辑 JSON 内容
   ↓
8. 点击"推送到 DB"保存
   ↓
9. 显示成功提示，表格自动刷新
```

### 8.2 导入流程

```
1. 点击"导入 JSON"
   ↓
2. 选择 role JSON 文件
   ↓
3. 预览导入的数据
   ↓
4. 确认导入 → 批量 POST 更新数据库
   ↓
5. 刷新表格显示
```

### 8.3 批量操作

