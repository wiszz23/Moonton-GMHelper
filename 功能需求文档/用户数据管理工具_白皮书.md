**版本**: 1.0
**日期**: 2026-05-15
**模式**: 混合编辑（表格 + JSON）
**关联项目**: GM 助手（GMHelper）v3.15+

## 1. 项目概述

### 1.1 工具定位

**用户数据管理工具** 是一个浏览器单文件 HTML 工具，提供**表格浏览 + JSON 编辑**混合模式，让运营人员快速查询、编辑、推送用户数据。

### 1.2 核心功能

- 🔍 **查询用户**：搜索 UID / 角色 ID / 用户名
- ✏️ **编辑数据**：表格 / JSON 两种模式自由切换
- 📌 **查看指令**：参考 public 指令内容
- 💾 **推送同步**：编辑后一键推送到数据库

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| 单文件部署 | 浏览器双击打开即可 |
| 零外部依赖 | 纯 JavaScript + CSS |
| 混合编辑 | 表格浏览 + JSON 编辑 |
| 灵活查询 | 搜索、筛选、分页 |
| JSON 美化 | 格式化、验证、语法高亮 |
| 指令参考 | 实时查看 public 指令 |
| 本地缓存 | 离线编辑 + 自动同步 |

## 3. 核心功能

### 3.1 查询用户

```javascript
// 支持三种查询方式
1. UID 搜索：输入 "10001"
2. 角色 ID 搜索：输入 "1001"
3. 用户名搜索：输入 "玩家A"

API: GET /api/gm/users?search=keyword&page=1&limit=50
```

### 3.2 编辑用户数据

**模式 A：表格查看**
- 显示用户列表
- 点击行选中用户

**模式 B：JSON 编辑**
- 显示完整 JSON
- 实时格式化
- 支持撤销 (Ctrl+Z)

### 3.3 查看 Public 指令

```javascript
// 点击"查看 Public 指令"
GET /api/commands/public
显示只读格式化 JSON
```

### 3.4 推送到数据库

```javascript
// 编辑完成后点击"推送到 DB"
POST /api/gm/users
请求体: 修改后的用户 JSON
返回: { code: 0, message: "保存成功" }
```

## 5. 后端 API

### 5.1 API 列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/gm/users?search=&page=&limit=` | 查询用户列表 |
| GET | `/api/gm/users/:uid` | 获取单个用户 |
| POST | `/api/gm/users` | 保存修改 |
| GET | `/api/commands/public` | 获取 public 指令 |

### 5.2 请求/响应

```javascript
// 1. 查询用户
GET /api/gm/users?search=10001&page=1&limit=50

Response:
{
  "code": 0,
  "data": {
    "users": [
      { "uid": "10001", "username": "玩家A", "character_id": "1001", ... }
    ],
    "total": 1,
    "page": 1
  }
}

// 2. 保存用户数据
POST /api/gm/users
Body: { "uid": "10001", "username": "玩家A", "level": 55, ... }

Response:
{
  "code": 0,
  "message": "保存成功",
  "data": { "uid": "10001", ... }
}

// 3. 查看 public 指令
GET /api/commands/public

Response:
{
  "code": 0,
  "data": {
    "装备": [
      { "name": "全身装备", "text": "add_gear %s 611210 1\n..." }
    ],
    "道具": [...]
  }
}
```

## 7. 部署

### 7.1 文件

```
gm-user-manager.html （单文件，<200KB）
```

### 7.2 使用

1. 将文件下载到本地
2. 双击打开
3. 首次打开时配置 API 地址（默认 http://10.30.138.5:3000）
4. 开始查询和编辑

### 7.3 配置

```javascript
// 可自定义的配置项
const CONFIG = {
  API_BASE_URL: 'http://10.30.138.5:3000',
  REQUEST_TIMEOUT: 10000,
  CACHE_EXPIRY: 3600000,
  PAGE_SIZE: 50
}
```
